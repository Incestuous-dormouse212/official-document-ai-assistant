## ⚙️ How to use the software

### Initial setup
When you open the application for the first time, you must select your document standards. These standards guide the repair tool. Pick the requirements that match the agency or department you submit your paperwork to.

### Processing documents
1.  Click the "Open" button to import your document.
2.  Select the document you want to check.
3.  Click "Start Review" to begin the analysis.
4.  The application highlights issues in the main window.
5.  Review each suggestion one by one. You can choose to accept the change or ignore it.
6.  Once you resolve all issues, click the "Apply Formatting" button to fix the layout.
7.  Save your work using the "Export" menu. Choose your file format from the provided list.
